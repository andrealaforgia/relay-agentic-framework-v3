### Design positions

**Contract protection.** I accept omitting a path importer for the PostgreSQL process contract. The remaining distinction is what the registered command invokes. If it launches the public VAT executable, its output is a real observation, even if the implementation handles only the registered input. If it launches a repository-owned acceptance wrapper, changing only that wrapper can turn the evidence green while the public executable still returns the old value. The Verifier should identify the public entry point at registration. Any verifier-owned wrapper or fixture needs to travel with the contract or be protected by digest. The architecture still promises ownership checks for those files.
